# Ledger 3: AI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add research briefs (per organisation and per person) and "Paste and summarise" in the quick log, calling the Anthropic API from the server only.

**Architecture:** `ledger/ai.py` is the only module that talks to the Anthropic API. It has two calls, `research(subject)` and `summarise(...)`, and a `FakeAI` with the same shape for tests and local development. A research run is a `research` row: `POST` makes it `running` and answers 202 at once, a background thread does the call and marks it `done` or `failed`, and the page polls until it ends. Summarise is a plain request that fills the quick log's form and saves nothing. The frontend gains a Research section on the organisation and contact pages, a "Research" group in search, and a "Paste and summarise" toggle in the quick log.

**Tech Stack:** Python 3.9, FastAPI, SQLite, `anthropic==0.125.0` (the newest release that supports Python 3.9). Model `claude-opus-5-5` with adaptive thinking, structured output (`output_config.format`), streaming, server-side fallback (`fallbacks: "default"`, beta `server-side-fallback-2026-07-01`), and for research the server tools `web_search_20260209` (`max_uses` 10) and `web_fetch_20260209`. Frontend as in plan 2: React 18, TypeScript, Tenon, Vitest, Playwright.

**Branch:** `feature/ai`, from `main` after plan 2's merge. Merge to `main` through a PR at the end.

## Decisions taken for this plan

- **SDK version.** `anthropic` 1.x needs Python 3.10, and Ledger is Python 3.9. Pin `anthropic==0.125.0`, the newest 0.x release. It has everything the spec needs: `fallbacks`, `output_config`, the `_20260209` web tools and `stream().get_final_message()`.
- **Which AI runs.** `LEDGER_AI` is `anthropic`, `fake` or `off`. Unset, it is `anthropic` when `ANTHROPIC_API_KEY` is set and `off` when it is not, so a machine with no key never calls out. `fake` gives canned answers for local development and Playwright, and is refused in header (server) mode. With `off`, the AI routes answer 503 and `GET /api/meta` says `ai: false`, so the page hides the buttons.
- **Background runs** are one daemon thread each, in the app's own process (uvicorn runs one worker). A run that is `running` when the app starts was cut off by a restart: startup marks it `failed` with "Stopped when the server restarted. Run it again."
- **One running job per record** is enforced twice: by a check inside the `BEGIN IMMEDIATE` that inserts the row (409 with `current`, the running row), and by a partial unique index as a backstop.
- **Cost.** Each run stores `model`, `input_tokens`, `output_tokens` and `web_searches`. The API adds `cost_usd`, worked out from a price table in `ledger/pricing.py` (US dollars, since that is how Anthropic bills): $4 / $20 per million tokens for `claude-opus-5-5`, plus $0.01 per web search. A model missing from the table (a fallback model not listed) shows no cost rather than a wrong one.
- **What a run is told** (as JSON inside `<known>` tags): the organisation's facts, its people, the last 20 interactions (for a person: the last 20 they took part in), and the latest finished brief for the same record, so a re-run updates it. Owner emails are not sent. A person's run also gets the person's own facts.
- **A person's brief** uses the same schema as an organisation's. Its `people` lists colleagues worth knowing.
- **"Add?" suggestions.** A suggested person is shown as a link when they already exist (same `contact_id`, or the same name ignoring case), and as an "Add?" button otherwise. The button creates the contact with name and role, and nothing else is added without a click.
- **Summarise's answer is checked** before it reaches the form: an unknown `type` becomes `note`, dates that do not parse become null, and `contact_ids` keep only this organisation's people. The server logs the token use of each summarise call; only research shows a cost.
- **Search** indexes a brief when its run finishes (`done` only), as kind `research`. A hit carries `contact_id`, so a person's brief links to their page (`/c/<id>#research`) and an organisation's to `/o/<slug>#research`.
- **About Offdesk.** The research prompt describes Offdesk in one constant, `ABOUT_OFFDESK` in `ledger/ai.py`. The plan ships a neutral sentence; the owner should replace it with what Offdesk actually sells, which is what `offdesk_angle` is written against.
- **The online test** (`pytest -m online`) makes one real research call and one real summarise call about a made-up company. It costs money, so it is run only when the owner says so, and never in CI.

```python
def message(stop="end_turn", text=None, content=None, inp=100, out=50, searches=0, category=None, model=MODEL):
    blocks = content if content is not None else ([NS(type="text", text=text)] if text is not None else [])
    return NS(
        stop_reason=stop, content=blocks, model=model,
        stop_details=NS(category=category) if stop == "refusal" else None,

class Stream:
    def __init__(self, msg):
        self.msg = msg

    def __enter__(self):
        return self

    def __exit__(self, *exc):
        return False

    def get_final_message(self):
        return self.msg


class Client:
    """Answers each stream() call with the next answer, raising it if it is an exception."""

    def __init__(self, *answers):
        self.answers = list(answers)
        self.calls = []
        self.beta = NS(messages=NS(stream=self.stream))

    def stream(self, **kw):
        self.calls.append(dict(kw, messages=list(kw["messages"])))
        answer = self.answers.pop(0)
        if isinstance(answer, Exception):
            raise answer
        return Stream(answer)
```

```python
"""What a run cost, in US dollars, from its token counts. Prices are per
million tokens, (input, output). A model not listed shows no cost, rather
than a wrong one: a server-side fallback can answer on another model."""

from typing import Optional

PRICES = {
    "claude-opus-5-5": (4.0, 20.0),
    "claude-opus-5": (5.0, 25.0),
    "claude-opus-4-8": (5.0, 25.0),
    "claude-sonnet-5-5": (2.0, 10.0),
    "fake": (0.0, 0.0),
}
WEB_SEARCH = 0.01  # each search: $10 per 1,000


def cost_usd(model: Optional[str], input_tokens: Optional[int], output_tokens: Optional[int],
             web_searches: Optional[int]) -> Optional[float]:
    price = PRICES.get(model or "")
    if price is None or input_tokens is None or output_tokens is None:
        return None
    total = input_tokens * price[0] / 1e6 + output_tokens * price[1] / 1e6 + (web_searches or 0) * WEB_SEARCH
    return round(total, 4)
```

```python
"""The one place Ledger calls the Anthropic API: on the server only, with
ANTHROPIC_API_KEY, so the browser never sees the key. The rest of the app
calls `research()` and `summarise()` on whatever `from_settings()` returns,
which is FakeAI in tests and local development.

Both calls use claude-opus-5-5 with adaptive thinking, stream the answer and
constrain it to a JSON schema. Research also searches and reads the web. If
the model declines, the API retries on another model by itself
(`fallbacks: "default"`); a decline that stands is an AIError."""

import json
import logging
from dataclasses import dataclass
from typing import Any, Dict, List, Optional, Sequence, Tuple

from .config import Settings
from .statuses import INTERACTION_TYPES

log = logging.getLogger("ledger.ai")

MODEL = "claude-opus-5-5"
BETAS = ["server-side-fallback-2026-07-01"]
MAX_STEPS = 6  # a turn with web tools can pause; resume it this many times at most

# What the research prompt says Offdesk is. Replace it with what Offdesk sells:
# `offdesk_angle` in each brief is written against it.

    "Offdesk is a small studio that takes on client projects. Its team uses Ledger "
    "to keep track of the organisations it talks to about work."

@dataclass
class Usage:
    model: str
    input_tokens: int = 0
    output_tokens: int = 0
    web_searches: int = 0


class AIError(Exception):
    """A call that ended without a usable answer. The message is for people;
    `usage` is what the call used before it ended."""

    def __init__(self, message: str, usage: Optional[Usage] = None):
        super().__init__(message)
        self.usage = usage


@dataclass
class Brief:
    brief: Dict[str, Any]
    sources: List[Dict[str, str]]
    usage: Usage


def _object(props: Dict[str, Any]) -> Dict[str, Any]:
    return {"type": "object", "properties": props, "required": list(props), "additionalProperties": False}


_TEXT = {"type": "string"}
_TEXTS = {"type": "array", "items": _TEXT}
_TEXT_OR_NULL = {"anyOf": [_TEXT, {"type": "null"}]}

BRIEF_SCHEMA = _object({
    "overview": _TEXT,
    "what_they_do": _TEXT,
    "size_and_funding": _TEXT,
    "people": {"type": "array", "items": _object({

    "likely_needs": _TEXTS,
    "offdesk_angle": _TEXT,
    "open_questions": _TEXTS,

SUMMARY_SCHEMA = _object({

RESEARCH_SYSTEM = """You research organisations and people for Offdesk ahead of sales conversations. %s

Search and read the web for current facts that can be checked. Prefer the organisation's own site, reputable news and public filings. When something is unknown, say so in a few words rather than guess. Write in British English, short and factual, with no marketing tone.

Every fact from the web needs its page in `sources`. In `people`, set `contact_id` to the id of a known contact when the person is one of them, and to null for someone worth adding. `offdesk_angle` is how Offdesk could help them, in two or three sentences. If a previous brief is given, update it: keep what still holds, correct what changed and add what is new.""" % ABOUT_OFFDESK

SUMMARY_SYSTEM = """You turn a pasted email, notes or a transcript into one log entry in Offdesk's record of a lead or client.

- `summary`: what happened and what was agreed, in a few plain sentences of British English, with no greeting or sign-off.
- `type`: call, email, meeting or note.
- `happened_at`: when it happened, as ISO 8601 with a time zone, or null if the text does not say.
- `next_step` and `next_step_due` (YYYY-MM-DD): the next action and its date, if the text states or clearly implies them. Otherwise null.
- `contact_ids`: the ids of the known people who took part. Never invent people or dates."""


def research_prompt(subject: Dict[str, Any]) -> str:
    what = "person" if subject.get("person") else "organisation"
    known = json.dumps(subject, indent=1, ensure_ascii=False, sort_keys=True)
    return "Research this %s and write the brief.\n\n<known>\n%s\n</known>" % (what, known)


def summary_prompt(text: str, org_name: str, contacts: Sequence[Dict[str, Any]], now_local: str) -> str:
    people = [{"id": c["id"], "name": c["name"], "role": c.get("role")} for c in contacts]
    return "Now: %s\nOrganisation: %s\nKnown people: %s\n\n<pasted>\n%s\n</pasted>" % (
        now_local, org_name, json.dumps(people, ensure_ascii=False), text)


def _add(usage: Usage, msg: Any) -> None:
    usage.model = msg.model or usage.model
    usage.input_tokens += msg.usage.input_tokens or 0
    usage.output_tokens += msg.usage.output_tokens or 0
    tools = getattr(msg.usage, "server_tool_use", None)
    if tools is not None:
        usage.web_searches += tools.web_search_requests or 0


class AnthropicAI:
    def __init__(self, client: Any = None):
        import anthropic  # loaded here, so FakeAI and the tests never need a key

        self._sdk = anthropic
        self.client = client if client is not None else anthropic.Anthropic(max_retries=3)

    def _ask(self, system: str, prompt: str, schema: Dict[str, Any], effort: str,
             tools: Sequence[Dict[str, Any]] = (), max_tokens: int = 64000) -> Tuple[Dict[str, Any], Usage]:
        sdk = self._sdk
        messages: List[Dict[str, Any]] = [{"role": "user", "content": prompt}]
        usage = Usage(MODEL)
        extra: Dict[str, Any] = {"tools": list(tools)} if tools else {}
        for _ in range(MAX_STEPS):
            try:
                with self.client.beta.messages.stream(
                    model=MODEL,
                    max_tokens=max_tokens,
                    system=system,
                    messages=messages,
                    thinking={"type": "adaptive"},
                    output_config={"effort": effort, "format": {"type": "json_schema", "schema": schema}},
                    betas=BETAS,
                    fallbacks="default",
                    **extra,
                ) as stream:
                    msg = stream.get_final_message()
            except sdk.RateLimitError:
                raise AIError("The AI service is busy. Try again in a minute.", usage)
            except sdk.APIStatusError as e:
                log.warning("AI call failed with %s, request %s", e.status_code, getattr(e, "request_id", None))
                raise AIError("The AI service returned an error (%d). Try again." % e.status_code, usage)
            except sdk.APIConnectionError:
                raise AIError("Could not reach the AI service. Try again.", usage)
            _add(usage, msg)
            if msg.stop_reason == "pause_turn":
                # The server paused its web-tool loop: send back what it has so far and it carries on.
                messages.append({"role": "assistant", "content": msg.content})
                continue
            if msg.stop_reason == "refusal":
                category = getattr(msg.stop_details, "category", None) if msg.stop_details else None
                raise AIError("The model declined this request%s." % (" (%s)" % category if category else ""), usage)
            if msg.stop_reason == "max_tokens":
                raise AIError("The answer was cut off before it finished. Try again.", usage)
            texts = [b.text for b in msg.content if b.type == "text"]
            try:
                return json.loads(texts[-1]), usage
            except (IndexError, ValueError):
                raise AIError("The answer was not in the expected shape. Try again.", usage)
        raise AIError("The research took too many steps. Try again.", usage)

    def research(self, subject: Dict[str, Any]) -> Brief:
        data, usage = self._ask(RESEARCH_SYSTEM, research_prompt(subject), BRIEF_SCHEMA, "high", WEB_TOOLS)
        sources = data.pop("sources", [])
        return Brief(data, sources, usage)

    def summarise(self, text: str, org_name: str, contacts: Sequence[Dict[str, Any]],
                  now_local: str) -> Tuple[Dict[str, Any], Usage]:
        return self._ask(SUMMARY_SYSTEM, summary_prompt(text, org_name, contacts, now_local), SUMMARY_SCHEMA,
                         "low", max_tokens=16000)
```

```sql
-- Research briefs, append only: each run is a row. A person's brief keeps its
-- organisation's id too, so deleting the organisation removes it, and search
-- can join it to the organisation like every other item.
CREATE TABLE research (
  id             INTEGER PRIMARY KEY,
  org_id         INTEGER NOT NULL REFERENCES organisations(id) ON DELETE CASCADE,
  contact_id     INTEGER REFERENCES contacts(id) ON DELETE CASCADE,
  status         TEXT NOT NULL CHECK (status IN ('running','done','failed')),
  brief          TEXT,
  sources        TEXT,
  model          TEXT,
  input_tokens   INTEGER,
  output_tokens  INTEGER,
  web_searches   INTEGER,
  error          TEXT,
  run_at         TEXT NOT NULL,
  finished_at    TEXT,
  author_email   TEXT NOT NULL
);
CREATE INDEX research_org ON research(org_id, run_at);
CREATE INDEX research_contact ON research(contact_id, run_at);

-- One running run per organisation brief and one per person. The repo checks
-- first and answers 409; these are the backstop.
CREATE UNIQUE INDEX research_one_running_org ON research(org_id)
  WHERE status = 'running' AND contact_id IS NULL;
CREATE UNIQUE INDEX research_one_running_contact ON research(contact_id)
  WHERE status = 'running' AND contact_id IS NOT NULL;

-- A brief is searchable once its run is done. Runs never change after that.
CREATE TRIGGER research_au AFTER UPDATE OF status ON research WHEN new.status = 'done' BEGIN
  DELETE FROM search WHERE kind = 'research' AND ref_id = new.id;
  INSERT INTO search(kind, ref_id, org_id, title, body) VALUES ('research', new.id, new.org_id,
    CASE WHEN new.contact_id IS NULL THEN 'Research brief'
```

```python
"""Research briefs, append only: each run adds a row. A row starts `running`
and ends `done`, with a brief and its sources, or `failed`, with the reason in
`error`. Nothing here writes to an organisation or its contacts, so a failed
or odd run cannot change them."""

import json
import sqlite3
from typing import Any, Dict, List, Optional

from ..db import now
from ..errors import Conflict, NotFound
from ..pricing import cost_usd
from . import contacts, interactions, orgs, row

INTERRUPTED = "Stopped when the server restarted. Run it again."
ORG_FACTS = ("name", "website", "sector", "size", "location", "kind", "status", "source", "tags", "summary",
             "next_step")
PERSON_FACTS = ("id", "name", "role", "relationship", "is_primary", "notes")


def _out(r: sqlite3.Row) -> Dict[str, Any]:
    d = row(r)
    d["brief"] = json.loads(d["brief"]) if d["brief"] else None
    d["sources"] = json.loads(d["sources"]) if d["sources"] else []
    d["cost_usd"] = cost_usd(d["model"], d["input_tokens"], d["output_tokens"], d["web_searches"])
    return d


def get(conn: sqlite3.Connection, research_id: int) -> Dict[str, Any]:
    r = conn.execute("SELECT * FROM research WHERE id = ?", (research_id,)).fetchone()
    if r is None:
        raise NotFound("No research %d" % research_id)
    return _out(r)


def list_for_org(conn: sqlite3.Connection, org_id: int) -> List[Dict[str, Any]]:
    """The organisation's own briefs, newest first. People's briefs are listed on their page."""
    orgs.get(conn, org_id)
    return [_out(r) for r in conn.execute(
        "SELECT * FROM research WHERE org_id = ? AND contact_id IS NULL ORDER BY run_at DESC, id DESC", (org_id,))]


def list_for_contact(conn: sqlite3.Connection, contact_id: int) -> List[Dict[str, Any]]:
    contacts.get(conn, contact_id)
    return [_out(r) for r in conn.execute(
        "SELECT * FROM research WHERE contact_id = ? ORDER BY run_at DESC, id DESC", (contact_id,))]


def _running(conn: sqlite3.Connection, org_id: int, contact_id: Optional[int]) -> Optional[sqlite3.Row]:
    if contact_id is None:
        return conn.execute("SELECT * FROM research WHERE org_id = ? AND contact_id IS NULL AND status = 'running'",
                            (org_id,)).fetchone()
    return conn.execute("SELECT * FROM research WHERE contact_id = ? AND status = 'running'",
                        (contact_id,)).fetchone()


def start(conn: sqlite3.Connection, by: str, org_id: Optional[int] = None,
          contact_id: Optional[int] = None) -> Dict[str, Any]:
    """A new running row: an organisation's brief, or a person's when contact_id is given."""
    conn.execute("BEGIN IMMEDIATE")
    try:
        if contact_id is not None:
            org_id = contacts.get(conn, contact_id)["org_id"]
        else:
            orgs.get(conn, org_id)
        busy = _running(conn, org_id, contact_id)
        if busy is not None:
            raise Conflict(_out(busy), "Research is already running")
        cur = conn.execute(
            "INSERT INTO research(org_id, contact_id, status, run_at, author_email) VALUES (?, ?, 'running', ?, ?)",
            (org_id, contact_id, now(), by))
        conn.execute("COMMIT")
    except Exception:
        conn.execute("ROLLBACK")
        raise
    return get(conn, cur.lastrowid)


def _previous(conn: sqlite3.Connection, r: Dict[str, Any]) -> Optional[Dict[str, Any]]:
    if r["contact_id"] is None:
        found = conn.execute(
            "SELECT brief FROM research WHERE org_id = ? AND contact_id IS NULL AND status = 'done' AND id != ? "
            "ORDER BY run_at DESC, id DESC LIMIT 1", (r["org_id"], r["id"])).fetchone()
    else:
        found = conn.execute(
            "SELECT brief FROM research WHERE contact_id = ? AND status = 'done' AND id != ? "
            "ORDER BY run_at DESC, id DESC LIMIT 1", (r["contact_id"], r["id"])).fetchone()
    return json.loads(found[0]) if found else None


def subject(conn: sqlite3.Connection, research_id: int) -> Dict[str, Any]:
    """What a run is told: the organisation's facts, its people, the last 20
    interactions (a person's own, for their brief) and the previous brief."""
    r = get(conn, research_id)
    org = orgs.get(conn, r["org_id"])
    if r["contact_id"] is None:
        history = interactions.list_for_org(conn, r["org_id"], limit=20)
    else:
        history = interactions.list_for_contact(conn, r["contact_id"])[:20]
    out: Dict[str, Any] = {
        "organisation": {k: org[k] for k in ORG_FACTS},
        "contacts": [{k: c[k] for k in PERSON_FACTS} for c in contacts.list_for_org(conn, r["org_id"])],
        "interactions": [{k: i[k] for k in ("type", "happened_at", "summary", "next_step")} for i in history],
        "previous_brief": _previous(conn, r),
    }
    if r["contact_id"] is not None:
        c = contacts.get(conn, r["contact_id"])
        out["person"] = {k: c[k] for k in PERSON_FACTS}
    return out


def _usage(usage: Any) -> Dict[str, Any]:
    if usage is None:
        return {}
    return {"model": usage.model, "input_tokens": usage.input_tokens, "output_tokens": usage.output_tokens,
            "web_searches": usage.web_searches}


def _end(conn: sqlite3.Connection, research_id: int, sets: Dict[str, Any]) -> None:
    """Ends a run that is still running. A run that already ended stays as it was."""
    sets["finished_at"] = now()
    conn.execute("BEGIN IMMEDIATE")
    try:
        conn.execute("UPDATE research SET %s WHERE id = ? AND status = 'running'"
                     % ", ".join("%s = ?" % k for k in sets), list(sets.values()) + [research_id])
        conn.execute("COMMIT")
    except Exception:
        conn.execute("ROLLBACK")
        raise


def finish(conn: sqlite3.Connection, research_id: int, brief: Dict[str, Any], sources: List[Dict[str, str]],
           usage: Any) -> None:
    _end(conn, research_id, dict(_usage(usage), status="done", brief=json.dumps(brief, ensure_ascii=False),
                                 sources=json.dumps(sources, ensure_ascii=False)))


def fail(conn: sqlite3.Connection, research_id: int, error: str, usage: Any = None) -> None:
    _end(conn, research_id, dict(_usage(usage), status="failed", error=error))


def fail_interrupted(conn: sqlite3.Connection) -> int:
    """At startup: a run still marked running was cut off by a restart."""
    conn.execute("BEGIN IMMEDIATE")
    try:
        n = conn.execute("UPDATE research SET status = 'failed', error = ?, finished_at = ? WHERE status = 'running'",
                         (INTERRUPTED, now())).rowcount
        conn.execute("COMMIT")
    except Exception:
        conn.execute("ROLLBACK")
        raise
    return n
```

```python
"""Background research runs: one daemon thread each, in the app's own
process. uvicorn runs one worker, and a run spends minutes waiting on the
API rather than working. A run still `running` when the app starts was cut
off by a restart; create_app marks it failed."""

import logging
import threading
from typing import Any, Callable

from .ai import AIError
from .db import connect
from .repo import research

log = logging.getLogger("ledger.jobs")


def run_research(db_path: str, ai: Any, research_id: int) -> None:
    conn = connect(db_path)
    try:
        try:
            out = ai.research(research.subject(conn, research_id))
        except AIError as e:
            research.fail(conn, research_id, str(e), e.usage)
            return
        except Exception:
            log.exception("research %d failed", research_id)
            research.fail(conn, research_id, "Research failed unexpectedly. Try again.")
            return
        research.finish(conn, research_id, out.brief, out.sources, out.usage)
        log.info("research %d done on %s: %d in, %d out, %d searches", research_id, out.usage.model,
                 out.usage.input_tokens, out.usage.output_tokens, out.usage.web_searches)
    finally:
        conn.close()


def in_thread(job: Callable[[], None]) -> None:
    threading.Thread(target=job, name="research", daemon=True).start()
```

```python
"""Paste and summarise: pasted text in, the fields of a log entry out. It
saves nothing: the quick log fills its form with the answer, for the person
to check and save. The answer is checked first, so the form only ever gets
values a log entry accepts."""

import datetime
import logging
import sqlite3
import zoneinfo
from typing import Any, Callable, Dict, Optional, Set

from fastapi import APIRouter, Depends, HTTPException, Request

from ..ai import AIError
from ..db import get_db
from ..repo import contacts, orgs
from ..schemas import SummariseBody, iso_date, iso_datetime
from ..statuses import INTERACTION_TYPES
from .research import need_ai

router = APIRouter()
log = logging.getLogger("ledger.ai")


def _parsed(check: Callable[[str], Optional[str]], v: Any) -> Optional[str]:
    if not isinstance(v, str) or not v.strip():
        return None
    try:
        return check(v.strip())
    except ValueError:
        return None


def _text(v: Any) -> Optional[str]:
    return v.strip() or None if isinstance(v, str) else None


def clean(answer: Dict[str, Any], known: Set[int]) -> Dict[str, Any]:
    ids = answer.get("contact_ids") or []
    return {
        "summary": _text(answer.get("summary")) or "",
        "type": answer.get("type") if answer.get("type") in INTERACTION_TYPES else "note",
        "happened_at": _parsed(iso_datetime, answer.get("happened_at")),
        "next_step": _text(answer.get("next_step")),
        "next_step_due": _parsed(iso_date, answer.get("next_step_due")),
        "contact_ids": sorted({i for i in ids if isinstance(i, int) and not isinstance(i, bool) and i in known}),
    }


@router.post("/summarise")
def summarise(body: SummariseBody, request: Request, db: sqlite3.Connection = Depends(get_db)):
    ai = need_ai(request)
    org = orgs.get(db, body.org_id)
    people = contacts.list_for_org(db, body.org_id)
    tz = request.app.state.settings.tz
    now_local = "%s (%s)" % (datetime.datetime.now(zoneinfo.ZoneInfo(tz)).isoformat(timespec="minutes"), tz)
    try:
        answer, usage = ai.summarise(body.text, org["name"], people, now_local)
    except AIError as e:
        raise HTTPException(502, str(e))
    log.info("summarise for org %d on %s: %d in, %d out", org["id"], usage.model, usage.input_tokens,
             usage.output_tokens)
    return clean(answer, {c["id"] for c in people})
```

```ts
import { useEffect, useRef } from 'react'

/** Calls `tick` every `ms` milliseconds while `ms` is a number; null stops it.
 * The latest `tick` is used, so callers need not memoise it. */
export function usePoll(ms: number | null, tick: () => void): void {
  const latest = useRef(tick)
  latest.current = tick
  useEffect(() => {
    if (ms === null) return
    const timer = setInterval(() => latest.current(), ms)
    return () => clearInterval(timer)
  }, [ms])
}
```

```tsx
import { useEffect, useState } from 'react'
import { useLocation } from 'react-router-dom'
import { ApiError } from '../api/client'
import { api } from '../api/endpoints'
import type { Contact, Research } from '../api/types'
import { useSession } from '../app/session'
import { day, label, person, usd } from '../lib/format'
import { useApi, type Loaded } from '../lib/useApi'
import { usePoll } from '../lib/usePoll'
import { BriefView } from './BriefView'
import { Loading } from './Loading'

export const POLL_MS = 3000

export interface Subject {
  kind: 'org' | 'contact'
  id: number
}

interface Props {
  subject: Subject
  orgId: number
  people: Loaded<Contact[]>
  /** How often to check a running run. Tests make it short. */
  pollMs?: number
}

const load = (s: Subject) => (s.kind === 'org' ? api.orgResearch(s.id) : api.contactResearch(s.id))
const startRun = (s: Subject) => (s.kind === 'org' ? api.startOrgResearch(s.id) : api.startContactResearch(s.id))

export function runLine(r: Research): string {
  return [day(r.run_at), person(r.author_email), label(r.status), usd(r.cost_usd)].filter(Boolean).join(' · ')
}

export function ResearchSection({ subject, orgId, people, pollMs = POLL_MS }: Props) {
  const { meta } = useSession()
  const { hash } = useLocation()
  const runs = useApi(() => load(subject), [subject.kind, subject.id])
  const [picked, setPicked] = useState<number>()
  const [starting, setStarting] = useState(false)
  const [error, setError] = useState<string>()

  const list = runs.data ?? []
  const running = list.some((r) => r.status === 'running')
  usePoll(running ? pollMs : null, runs.reload)

  // The header's Research link and search hits point at #research.
  useEffect(() => {
    if (hash === '#research' && runs.data) document.getElementById('research')?.scrollIntoView?.({ block: 'start' })
  }, [hash, runs.data])

  const latest = list[0]
  const shown = list.find((r) => r.id === picked && r.brief) ?? list.find((r) => r.status === 'done')

  async function start() {
    if (starting || running) return
    setStarting(true)
    setError(undefined)
    try {
      const r = await startRun(subject)
      runs.setData((prev) => [r, ...(prev ?? [])])
      setPicked(undefined)
    } catch (e) {
      setError(e instanceof Error ? e.message : 'Could not start the research.')
      if (e instanceof ApiError && e.status === 409) runs.reload()
    } finally {
      setStarting(false)
    }
  }

  return (
    <section className="lg-section" id="research">
      <div className="lg-section-head">
        <h2 className="tenon-heading-3">Research</h2>
        {meta.ai && (
          <Button size="sm" variant="secondary" disabled={starting || running} onClick={() => void start()}>
            {list.some((r) => r.status === 'done') ? 'Research again' : 'Research'}
          </Button>
        )}
      </div>
      {error && <Alert tone="error">{error}</Alert>}
      {runs.error && !runs.data ? (
        <Alert tone="error">{runs.error.message}</Alert>
      ) : !runs.data ? (
        <Loading />
      ) : (
        <>
          {running && (
            <p className="lg-running">
              <Spinner variant="ring" size="sm" label="Researching" />
              Researching. It takes a few minutes, and you can leave this page.
            </p>
          )}
          {latest?.status === 'failed' && (
            <Alert
              tone="error"
              title="The last research run failed"
              actions={meta.ai && <Button size="sm" variant="secondary" disabled={starting} onClick={() => void start()}>Retry</Button>}
            >
              {latest.error}
            </Alert>
          )}
          {shown?.brief ? (
            <BriefView run={shown} orgId={orgId} people={people} />
          ) : (
            !running && latest?.status !== 'failed' && (
              <p className="lg-faint">
                {meta.ai ? 'No research yet. It searches the web and writes a brief.' : 'No research yet. AI is not set up on this server.'}
              </p>
            )
          )}
          {list.length > 1 && (
            <div className="lg-field">
              <span className="tenon-label">Runs</span>
              <ul className="lg-runs">
                {list.map((r) => (
                  <li key={r.id}>
                    <Button size="sm" variant="ghost" aria-pressed={shown?.id === r.id} disabled={!r.brief} onClick={() => setPicked(r.id)}>
                      {runLine(r)}
                    </Button>
                  </li>
                ))}
              </ul>
            </div>
          )}
        </>
      )}
    </section>
  )
}
```

```ts
/** The form after a summary: the summary's values where it has them, the form's where it does not.

export function fromSummary(f: LogFormState, s: Summary, types: string[], known: Set<number> | undefined): LogFormState {

}
```
